&#x20;                                                             **Desktop vs Web vs Mobile Apps**



Type	                               Example	                                                              How users interact



Desktop App	                  Microsoft Word	                   It is installed on a computer and users interact with it using a keyboard, mouse and computer screen. 

&#x20;                                                                          It can perform many tasks directly on the computer.



Web App	                            Google Docs	                           Users open it through a web browser such as Chrome or Edge. 

&#x20;                                                                          They can create and edit documents through the browser without installing the main application on their computer.



Mobile App	                    Instagram	                           It is designed for smartphones and users mainly interact using touch gestures such as tapping, swiping and typing.

&#x20;                                                                          It can also use phone features such as the camera and notifications.
